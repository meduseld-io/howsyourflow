# howsyourflow.io

The public project page for **current**, a local board that puts your Jira tickets and
GitHub pull requests on one page, ranked by what needs you first.

This repository holds only the published site: the landing page, the documentation, and
their stylesheets, fonts and images. It exists because GitHub Pages does not serve a
private repository on a free plan, and the project itself is private.

The source of truth is `docs/` in the project repository. Changes are published from there
rather than edited here.
